# Exploratory Data Analysis (EDA) Project

## Objective

Analyze the Titanic dataset to discover patterns, trends, and relationships among variables.

## Dataset

Titanic Dataset

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Analysis Performed

* Data inspection
* Statistical summaries
* Missing value analysis
* Survival analysis
* Gender analysis
* Age distribution analysis
* Passenger class analysis
* Correlation analysis

## Key Findings

* Female passengers had a higher survival rate.
* Most passengers were between 20 and 40 years old.
* Third-class passengers were the largest group.
* Passenger class and gender strongly influenced survival.
* Fare showed a positive relationship with survival.

## Outcome

Developed analytical thinking, data exploration, and visualization skills through Exploratory Data Analysis.
